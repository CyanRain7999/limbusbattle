# 后续罪人设计腹稿 · 2026-10-24

本文件是玩法提案，尚未接入选人或实战。先把现有两人的连招、防御、空战打磨稳定，再按以下批次扩展。

## 所有人共用的制作标准

- **LCB 服装和武器是角色锚点。** 六键普通技表示两组轻中重武器攻击，不能套成统一徒手拳脚。站、蹲、空中各六种，出招方向和握持方式要能从剪影辨认。
- 默认普通技维持 LCB。人格必杀只在招式期间切换服装、武器、特效，收招或受击恢复。每人至少六个地面搓招，本作现行七槽全部保留；空中两个独立搓招。
- 每人至少完成：跳入 → 地面确认 → 必杀；下段确认；浮空 → 空中追击。连段计数只在对手持续不能行动时相连，不能靠长时间显示数字伪造连段。
- 空中不依靠方向输入改变轨迹；人格技能若将来需要改变轨迹，必须作为单独的明确招式机制设计，不能顺手加回空中移动。
- 先制作 LCB 正侧面轮廓、握柄与武器长度对照图，再做姿势。统一约 64 像素体高，避免用高分辨率细节掩盖错误轮廓。

角色与 LCB 外观以 [Project Moon 官方角色页](https://limbuscompany.com/#Character) 为参考入口；原作人格名称、版本、武器与招式姿态在正式制作前逐张比对立绘。以下技能功能和机制均为本作提案，不宣称是原作已有技能。来源人格暂不硬填，避免选错人格或武器。

## 第一批：补上当前阵容缺少的对局类型

### 以实玛利：盾与钉头锤的防守反击

锚点：盾始终随身，短打用盾边和锤柄，重打用锤头。面向对手的防守姿态与后退动作要保留盾的遮挡层次。

七个地面功能槽：236J 短程盾推；214K 盾架反击；623L 锤头挑击对空；22J 消耗资源强化下一次盾击；236K 带破绽的推进锤击；214L 低位锤扫；623J 高消耗反压制。

空中两槽：236J 斜下锤击确认；214K 盾面压落攻击。两招沿起跳轨迹运动。特色为挡住攻击后获得一次短暂的反击奖励，不能永久保持霸体。盾推有推开作用，近身投可以克制她；空挥重锤必须能被确反。

### 默尔索：拳套与近身擒投

锚点：LCB 拳套和前臂结构必须清晰，拳套是武器，不做所有罪人的通用打拳模板。普通技以短促直击、架肘、重摆和前臂压制区分。

七个地面功能槽：236J 短程前臂冲击；214K 指令投；623L 近身挑击；22J 短时承受一次攻击；236K 低位推进；214L 读取对手后反击；623J 有明显前摇的高回报抓取。

空中两槽：236J 下压拳套；214K 横向扫臂。先复用地面投 / 拆投规则；指令投不从命中硬直中强抓，普通投有拆投窗口。以较慢前进与较短普通技射程交换近身收益。建议先做普通投派生，避免一开始引入一整套复杂空投判定。

### 良秀：带鞘长刀的差合与反击

锚点：LCB 动作保留刀鞘，不能为了发光刀刃让基础形态随意拔刀。刀鞘端击、横扫、挑击与双手重击形成六键普通技。其他人格的独立武器在对应必杀期间出现。

七个地面功能槽：236J 快速直线斩击；214K 后撤反击；623L 狭窄对空；22J 架势准备；236K 中段距离突进；214L 低位横扫；623J 消耗准备状态的多段终结。

空中两槽：236J 斜下刀鞘击；214K 横向截击。强项是抓空挥，弱点是贴身被压时缺少稳定无敌解围。不能同时拥有最快普通技、最长射程和安全大伤害。

## 第二批：拉开距离、节奏和武器覆盖的差异

| 罪人 | LCB 锚点与普通技方向 | 对局目标 | 七个地面搓招的功能腹稿 | 两个空中搓招的功能腹稿 |
|---|---|---|---|---|
| 浮士德 | 双手大剑；短握柄击、平斩、挑斩、剑身压击 | 慢起手的中距离控制；命中后稳定带入角落 | 短剑风、后撤斩、挑剑、准备、重推进、低扫、长收招终结 | 斜下剑击、空中横截 |
| 鸿璐 | 长柄刀；刺、柄击、转腕横扫，武器长柄保持可读 | 可选择追击或保留距离，靠间合变化压制 | 直刺、回身扫、挑刀、蓄势、滑步斩、低位扫、长柄连击 | 向下劈斩、反手截击 |
| 罗佳 | 大斧；斧柄快击与斧刃重砸明显分开 | 慢速高回报；命中后有强压起身，但空挥危险 | 短砸、后撤钩斧、上挑、蓄力、推进劈、地面扫、重终结 | 斧刃下落、横向封空 |
| 辛克莱 | 长戟；刺端、钩端、斧刃分别承担轻中重用途 | 有节奏的长柄压制，确认后爆发 | 戟刺、回收钩、挑戟、节奏准备、推进斩、地面钩扫、连击终结 | 下刺、斜劈 |
| 奥提斯 | 按 LCB 立绘复核刀刃武器及枪械结构，普通技保留实体刀刃 | 有资源限制的中远距离控制，不能无限退后射击 | 短射击、撤步斩、对空、装填准备、推进刺、低扫、集中射击 | 斜下单发、下切 |
| 李箱 | 短刃与持刃姿势；短刺、反握截击、挑击 | 短射程快确认；用设置型人格技能换取位置优势 | 快刺、后撤截击、挑刃、设置、推进连刺、低位切、设置引爆 | 下刺、反手横切 |
| 格里高尔 | 虫臂、肩部与身体轮廓；普通技从虫臂结构展开 | 不同长度的虫臂攻击与中距离消耗 | 短刺、回收扫、抬臂挑、硬壳准备、长伸刺、地面钩、连段终结 | 斜下虫臂刺、横扫 |

李箱的设置、奥提斯的装填、格里高尔的延伸虫臂是可选的角色机制；先把基础九种搓招与可靠连段做完，再加入独立状态。不能为了体现特色堆叠难以读懂的计量表。

## 每名新罪人的交付顺序

1. 固定 LCB 立绘与至少六个来源人格的参考清单，记录版本、服装、持武器方式和武器外形。
2. 做约 64 像素体高的待机与站立六普通技，确认角色辨识后补蹲 / 空动作、移动与受击。
3. 接入地面搓招和两招空中搓招，每招必须有独立用途；准备、反击、远程与终结不能只是换颜色。
4. 逐个确认跳入、下段、浮空三个实用路线，检查远近距离与墙角；补能被对手克制的空档。
5. 最后接 AI、手柄 / 手机布局兼容与离线资源打包。没有完成动作和判定前，不解锁可玩槽位。
