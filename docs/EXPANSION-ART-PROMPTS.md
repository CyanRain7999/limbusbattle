# 四名罪人像素动作 · 2026-10-24

模式：内置 imagegen，按立绘和战斗模型参考生成原创像素动作；未使用 CLI 或复用官方精灵。

每人两张基础原图：`public/characters/{sinner}/lcb/source-sheet.png`（18 姿势）与 `normals/source-sheet.png`（18 种武器普通技）。每个人格另有独立六姿势小表。原图、对齐表与元数据全部留在对应目录，发布仅使用 `public/runtime` 的最近邻小图。

角色目标约 64 像素体高；高帽和鹿角允许额外高度。罗佳两张基础表采用三列六行，以实玛利四协采用两列三行，给横向武器留空。其他基础表为六列三行，人格一般三列两行。

参考清单见 [EXPANSION-REFERENCES.json](EXPANSION-REFERENCES.json)。立绘 / 战斗模型参考缓存仅位于 `.cache/references/roster-2026/`，不复制进仓库或发布。黄蜂鸟枪独头弹、惜春折扇、血魔公主紫伞、拇指延刃剑以用户纠正为最终依据，已分别重画六姿势并修改动作逻辑。

基础图对齐：`python scripts/prepare-expansion-atlases.py`；人格图对齐：`python scripts/prepare-personas.py`；运行图：`python scripts/build-pixel-atlases.py`。

以下是最终选用版本的完整提示词。
