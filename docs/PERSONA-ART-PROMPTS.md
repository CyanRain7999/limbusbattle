# 人格动作图生成记录

按照人格原立绘与战斗模型参考制作原创动作图，非官方原图切片。保留源 PNG，运行时采样成约 64 像素体高的最近邻贴图。每人格六个姿势。参考来自 https://www.limbuscompany.tools/identities ，仅在本地缓存用于对照，不随游戏发布。

## don-n

Use case: stylized-concept. Create NEW game art, an isolated low-resolution pixel-fighter attack animation sheet. Reference 1 is canonical portrait for clothing and face; Reference 2 is full-body battle design for silhouette and exact weapon, IGNORE website controls, loading graphics and background. Reinterpret these as original pixel art, never copy reference pixels. True 48×64-body pixel art look: limited 20–24 colors, 2–3 flat shades/material, tiny eyes, four-head-tall compact body, clearly visible square pixel clusters, no microtexture or smooth illustration. Precisely THREE COLUMNS × TWO ROWS, 6 equal cells, landscape canvas. One complete SAME fighter in each cell, all facing RIGHT, same scale and baseline, entire weapon inside cell, generous transparent gutters. Read left to right top row then bottom row: ready (weapon low, head highest body point), windup, attack startup, full attack to RIGHT, follow-through, recovery. No grid, labels, letters, numbers, scenery, floor shadow, loading symbols, checkerboard or matte. TRUE transparent RGBA background.
Subject and action: Don Quixote as N Corp Mittelhammer. Blonde bob; heavy worn silver cathedral plate armour with many ivory parchment seal strips and dark RED wax seals, black underclothes and boots. Huge BLACK and dark RED RECTANGULAR MAUL on long dark handle and a dark nail/spike. Match the reference maul shape, armour and seals. Six powerful overhead hammer slam poses, weapon sweeps down to right.
