# 李箱、奥提斯、格里高尔 · 制作记录

2026-10-24：三人已实装。每人六个指定人格 + LCB 共七地面指令、两空中指令、站 / 蹲 / 空各六个武器普通技。李箱采用用户确认的 LCE「裂维者」。浮士德、鸿璐、辛克莱仍未实装。

## 美术规格

按用户对李箱的反馈，废弃大头、大眼、圆脸、平滑阴影的初稿。最终以旧良秀 LCB 表直接作为编辑与比例参考：约四头身、较长躯干与腿、小眼侧面轮廓、硬边像素色块。保留每人的发型、衣装与武器；李箱移除误带的烟。

每人分两张十八姿势基础表生成，分别为 LCB 动作与武器普通技；十八个人格各自生成六姿势表。最终提示词见 [NEXT-THREE-ART-PROMPTS.md](NEXT-THREE-ART-PROMPTS.md)。源图在 public/characters，运行时最近邻采样到约 64 像素体高，只加载 public/runtime 图集。

## 本作机制

| 罪人 | LCB 武器 | 特点与限制 | 连段示例 |
|---|---|---|---|
| 李箱 | 短匕首 | 623J 在前方 165 距离布置镜痕，持续 210 帧、最多一个。下次地面人格进入有效帧时消耗，12 帧后在原位置追击 55 基础伤害；可走位 / 跳跃避开。普通技、空中技不触发。 | 布置 → J → K → L → 623L |
| 奥提斯 | kopis 曲刀 | 地面 / 空中魔弹共用三发。空仓再次地面 236J 改为 28 帧装填 + 13 帧收招，无攻击、可打断；空中不能装填。刀和其他人格不耗弹。 | J → K → L → 214K；安全距离装填 |
| 格里高尔 | 附着右臂的分节虫爪 | 按住地面重普通技可蓄力最多 18 帧，加 65 距离；松开可提前释放。有效帧与最初 6 帧收招的伸臂有受击框。空中不蓄力。 | J → K → L → 214K；中距离按住 O 再松开 |

镜痕、三发装填与虫臂蓄力是本作格斗规则，不宣称为原作同名机制。伤害、范围、帧数和空中技均作改编；六姿势生成动画也不等于逐帧复刻原作。

## 输入与特效

- 623 独立窗口 40 帧、相邻关键方向最多 20 帧、末尾攻击键宽限 14 帧；支持 623、6236、636、323，左右朝向及 J / L 适用。236 / 214 仍为 34 / 16 / 12 帧。单方向和不完整结构仍是普通技。
- 武器普通技三档：轻为薄短刃迹与四枚命中碎片；中为双层刃迹、拖尾与九枚碎片；重为多层残影、边缘碎片、冲击纹与十六枚碎片。范围、持续时间和命中爆点均不同。站 / 蹲 / 空、副武器键及冲刺普通技按强度分档，并跟随武器方向。
- 人格另有花瓣、黑白蝶、点彩笔痕、爪痕、电弧、喷焰和硬血剪切。装填不播放射击特效。
